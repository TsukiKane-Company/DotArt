# ドット絵メーカー by 月兼ホッパー

写真をドット絵に変換したり、白紙のマス目にドット絵を描いたりできる小さなツールです。

## できること
- 写真をドット絵に変換（長い辺 16〜128 マス）
- パレット：月兼／ゲームボーイ風（緑 4 色）／黒緑ターミナル／自動（元画像から色を拾う）
- ディザリング（網かけ）、グリッド線の表示
- 白紙（16×16〜64×64）に描く：ペン、消しゴム、塗りつぶし、スポイト、元に戻す／やり直す、全消し
- アイロンビーズ図面：番号付きのマス目と、色ごとのビーズの数
- PNG で保存（1倍／4倍／8倍／最大）、図面も PNG で保存

## 使い方
1. 画像をドロップするか、クリックして選ぶか、Ctrl+V で貼り付けます。白紙から描くときはサイズを選んで「白紙から描く」を押します。
2. パレットやドットの数を調整し、必要ならペンなどで手直しします。
3. 「PNG で保存」または「図面を PNG で保存」を押します。iPhone では表示された画像を長押しして保存します。

## データについて
処理はブラウザの中だけで行います。画像はどこにも送りません。ログインは不要で、外部のサーバーやフォントは読み込みません。
